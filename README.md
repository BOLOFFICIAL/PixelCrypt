# PixelCrypt

PixelCrypt — настольное приложение для Windows на базе WPF (.NET 8), которое объединяет криптографию и стеганографию для защиты данных в изображениях.

## Возможности

Приложение содержит два инструмента:

### 1. Криптография
Шифрование изображений путём разбиения на блоки и их перестановки по перестановке, порождаемой паролем (seed из SHA-256).
- **Encrypt** — превращает изображение в «визуальный шум»: без ключа исходник не восстановить.
- **Decrypt** — восстанавливает исходное изображение по тому же паролю.
- **Interference** (10–100 %) — задаёт степень «перемешивания»: влияет на размер и количество блоков.

### 2. Стеганография
Скрытое встраивание текста или файла в изображение (запись битов через чётность младшего бита цветовых каналов). Перед встраиванием данные шифруются AES-256.
- **Import** — скрывает данные в одном или нескольких изображениях (автоматическое распределение данных между изображениями).
- **Export** — извлекает и собирает данные обратно (включая восстановление файла с именем и расширением).
- Опция **Index dependence** — записывать/учитывать порядок частей данных.

### Общие возможности интерфейса
- Добавление изображений: выбор файлов, папок (с учётом подпапок), drag & drop, вставка из буфера обмена.
- Управление списком: перемещение, удаление, открытие оригинала.
- Прогресс выполнения с процентами и таймером, остановка операции.
- Сохранение результата в папку, в файл или копирование в буфер обмена.
- Уведомления о результатах операций (успех / ошибка / вопрос).
- Автоматическое обновление через фоновый апдейтер (GitHub Releases).

## Архитектура

Проект построен по паттерну **MVVM**:

```
PixelCrypt2026/
├── Commands/     # команды (LambdaCommand, Command)
├── Model/        # модели данных
├── Program/      # бизнес-логика: шифрование, стеганография, работа с пикселями и файлами
│   └── Service/  # навигация, статус операций
├── Style/        # стили и тема оформления
├── View/         # XAML-страницы и окна
├── ViewModel/    # view-модели (Base, Page, UserControl, Window)
├── App.xaml
├── PixelCrypt2026.csproj
└── PixelCryptLogo.ico
```

Ключевые модули логики:
- `Encryption` — AES-шифрование текста и блочное шифрование/дешифрование изображений.
- `Converter` — преобразование текста ↔ бинарная строка.
- `ImageHelper` — чтение/запись пикселей (`byte[]` + `LockBits`), импорт/экспорт данных в изображение.
- `MatrixBlockUtils` — расчёт размеров блоков и перестановка блоков.
- `FileHelper`, `ProgramHelper` — работа с файлами, хеши, буфер обмена.

## Требования

- Windows 10 или новее
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## Сборка

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
dotnet build PixelCrypt2026/PixelCrypt2026.csproj -c Release
```

Публикация в папку (профиль `FolderProfile`):

```powershell
dotnet publish PixelCrypt2026/PixelCrypt2026.csproj -c Release -p:PublishProfile=FolderProfile
```

Результат: `PixelCrypt2026/bin/Release/net8.0-windows/publish/`

## Использование

1. Выберите инструмент: **Cryptography** или **Steganography**.
2. Добавьте одно или несколько изображений (файлы, папки, drag & drop или вставка).
3. Введите пароль.
4. Настройте параметры (режим, Interference / Index dependence).
5. Нажмите **Start** и дождитесь завершения.
6. Сохраните результат в папку, в файл или скопируйте в буфер обмена.
